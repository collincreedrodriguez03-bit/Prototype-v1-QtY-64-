# QtY 64 Selected BTC Live Data Source: Binance Public Spot WebSocket API

## 1. Selected Exchange & Endpoint
- **Exchange**: Binance Public Spot API
- **Endpoint / Protocol**: `wss://stream.binance.com:9443/ws/btcusdt@trade` (WebSocket WSS protocol)
- **Symbol**: `BTCUSDT` (Bitcoin / Tether USD spot market)

## 2. API / WebSocket Behavior & Specifications
- **Protocol**: Real-time WebSocket streaming. Emits trade execution events (`@trade`) as JSON objects upon each executed market match.
- **Timestamp Semantics**:
  - `E` (Event time): Millisecond epoch timestamp generated by the exchange matching engine when the trade occurred (preserved as exchange timestamp).
  - `T` (Transaction time / Receipt time): Millisecond epoch timestamp recorded upon packet receipt or message parsing.
- **Payload Schema**:
  ```json
  {
    "e": "trade",
    "E": 1700000000123,
    "s": "BTCUSDT",
    "t": 123456789,
    "p": "95200.50",
    "q": "0.05000000",
    "b": 123456788,
    "a": 123456790,
    "T": 1700000000125,
    "m": true,
    "M": true
  }
  ```
- **Rate Limits**: 5 incoming connection updates per second per IP; up to 1024 streams per connection. Generous for single-symbol BTC live monitoring.
- **Limitations**: Public WebSocket feeds may experience transient disconnects due to network routing or exchange maintenance. QtY handles this via automatic reconnection with exponential backoff and fail-closed state propagation (emitting `FEED_DISCONNECTED` or `STALE` rather than synthesizing false prices).

## 3. Why It Satisfies QtY Requirements
1. **Direct Stream**: Provides real-time trade ticks immediately without requiring HTTP polling overhead.
2. **Millisecond Timestamps**: Exposes exact exchange-level matching engine timestamps (`E`) and receipt timestamps (`T`).
3. **High Liquidity & Accuracy**: `BTCUSDT` spot market on Binance represents one of the deepest global BTC price discovery venues.
4. **Interchangeability**: Implements `BtcLiveMarketDataProvider`, ensuring QtY's core engine remains decoupled from Binance specifically.
